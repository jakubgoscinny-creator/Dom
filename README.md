# Dom

Projekt do zarządzania wszystkimi domowymi potrzebami remontowo-logistycznymi.

## Struktura

- **Remont/** — prace remontowe, planowanie, postęp
- **Logistyka/** — organizacja domowa, przeprowadzki, transport
- **Zakupy/** — listy zakupów, porównania cen, zamówienia
- **Finanse/** — budżety, wydatki, rozliczenia
- **Dokumenty/** — umowy, gwarancje, faktury, instrukcje
